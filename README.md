# 台灣時令蔬果防雷曆

一個給一般人「自主防雷」的台灣蔬果產季速查工具。單一 HTML 檔，無相依套件、無 build step。

> **攤商可以對「產地」說謊，但「當季不當季」騙不了人。**

進口蔬果的農藥疑慮、「洗產地」（例如中國蔬菜經第三地轉標）、傳統市場無標示只能靠口頭問——一般消費者其實無從查證。但產季是查得到的：**現在不是台灣產季、卻標「在地新鮮」的蔬果，很可能是進口或洗產地**。所以「知道現在真正該買什麼」本身就是最好的照妖鏡。

## 功能

- **二十四節氣轉盤**：畫面下緣的圓盤取代線性滑桿，一圈 36 旬。外圈是節氣、內圈是月‧旬，拖曳有慣性與吸附。時令本來就是循環的，圓盤在 12 月→1 月不會有斷崖。
- **時令看板**：開啟即自動對齊今天，列出當季蔬菜與水果。標「↑新上市」「↓把握最後」，並把「這旬新上市」挑到最上方。
- **照妖鏡反查**：輸入任一蔬果，立刻知道它台灣本地幾月才當季、現在該不該買。查到多個相似品項時會先列出候選讓你挑，不會自作主張猜一個。
- **年輪走勢圖**：點任一品項跳出徑向年輪——外圈粗弧＝產季月份，內圈曲線＝盛產強弱，虛線＝價格區間示意，並同時標出「今天」與「正在查看的月份」。
- **進口燈號**：標出「就算在產季也常有進口」的品項（葡萄、椪柑、柳橙、大蒜、洋蔥等），避免「當季」帶來的安全感陷阱。
- **手機版**：桌機 hover、手機單點；手機上的走勢卡改為底部彈出（bottom sheet）。
- **深淺色主題**：淺色／深色／跟隨系統三態皆處理。

## 資料來源

皆為官方或可查證的公開資料：

- **各月份可供應之國產蔬菜、水果品項參考資料**（農業部，107 年修訂版）— 主要產季資料
- **農業知識入口網**（kmweb.moa.gov.tw）— 盛產月份交叉比對
- 盛產期修正依據：農業部食農教育平臺、臺南／桃園區農業改良場
- 進口大宗品項依據：農業部進出口統計與公開報導

## 誠實界線

這個專案反覆處理「好用」與「不誤導」的平衡，幾個刻意的取捨：

- **不把「非產季＝進口」做成紅字判決**，只做成提醒查證的燈號。冷藏庫存、溫室、高山栽培都會讓本地產品合法出現在產季外。
- **旬與節氣都不是另造的資料**。官方產季以「月」為單位，上／中／下旬只用來表達同月內「剛上市→盛產→把握最後」的強弱；節氣則是依概略公曆日期換算到同一條年度刻度上。
- **走勢曲線標明「非實測產量」**，價格線標明「非實際市場調查」——目前都是依官方月表推估，不假裝是真實數字。
- **全年供應不假造季節**。真正全年連續生產的品項（葉菜、菇類等）誠實標為「全年供應、季節非判斷依據」，而不是硬塞一個假的窄產季。

## 開發

單一檔案，沒有建置流程。直接開啟即可：

```bash
open index.html
```

所有 HTML／CSS／JS 與資料都內嵌在 `index.html`。產季資料以 JS 物件形式集中在 `<script>` 開頭（`V` ＝蔬菜、`F` ＝水果、`SEASON_OVERRIDE` ＝盛產期修正、`IMPORT_COMMON` ＝進口燈號），易於維護替換。

「今天」由瀏覽器的 `new Date()` 自動偵測，不需要伺服器。

### 幾個改動時要知道的事

- 時間選擇畫面上是 SVG 轉盤，但**真值來源是隱藏的 `<input type=range min=0 max=35>`**（36 旬）。要改時間邏輯請動那個 input，轉盤會跟著走；它同時也是鍵盤與輔助技術的操作對象。
- 本檔目前**沒有 DOCTYPE、跑在 quirks mode**。牽涉視窗尺寸時請用 `window.innerHeight`，不要用 `document.documentElement.clientHeight`。
- 若把檔案複製到其他環境，**務必保留 `<meta name="viewport">`**；少了它手機會以 980px 寬渲染再縮小，整頁字級失效。

## 部署

純靜態站，`index.html` 在根目錄，任何靜態主機都能直接託管，不需要 `vercel.json` 或任何設定。

Vercel：於 [vercel.com/new](https://vercel.com/new) import 本 repo，framework preset 選 **Other**，直接 Deploy 即可。之後每次 push 會自動重新部署。
